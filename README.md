# 33 Works

> 把真實工作裡反覆、麻煩的小問題，做成一般人也能使用的工具。  
> Turning everyday workflow problems into practical, approachable tools.

33 Works 專注於 Windows 實用工具、內容工作流程與生活友善應用。作品來自真實使用需求，重視清楚操作、本機處理、安全確認與可恢復性。

## Featured projects｜主打作品

### [Whisper Transcriber](https://github.com/dw5000tw-33/whisper-transcriber)

Windows 語音轉文字工具，支援本機音訊與 YouTube 音訊，提供一鍵安裝流程。

A Windows transcription tool powered by Whisper, with local audio and YouTube support.

### [33 Works Logo Batch Tool](https://github.com/dw5000tw-33/33works-logo-batch-tool)

免費圖片批次加 Logo 工具，支援整批處理、單張微調、專案保存及 PNG／JPG／WebP 輸出；圖片全程在本機處理。

A local-first batch logo and watermark tool for Windows.

### [高齡駕駛認知練習](https://github.com/dw5000tw-33/c71-cognitive-practice)

為高齡使用者設計的 Android 認知練習工具，可安裝後離線使用。

An offline-friendly Android cognitive practice app designed for older users.

## Community projects｜社群作品

### [DChurch](https://github.com/dw5000tw-33/DChurch)

教會聚會、破冰遊戲與數位內容協作工具。

Digital tools and interactive resources for church gatherings and community activities.

## What we value｜我們重視的事

- Solve a real problem｜從真實問題出發
- Clear before clever｜操作清楚比功能炫技重要
- Local-first when possible｜能在本機完成，就不要求上傳資料
- Review before destructive actions｜重要動作先預覽、再確認
- Honest limitations｜清楚說明工具做得到與做不到的事
